# Wispr Flow meeting outputs

Wispr Flow is the source of truth for meeting transcripts. This repository holds
generated or curated outputs derived from those transcripts, organized by account.

Store outputs by account, then by meeting date or topic:

```text
accounts/
  acme-corp/
    2026-10-15-quarterly-review.md
```

Use lowercase, hyphenated account folder names. Keep generated outputs in Markdown
so they remain easy to search, diff, and automate. Do not copy raw transcripts
here unless an account workflow specifically requires it.
